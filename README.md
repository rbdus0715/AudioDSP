# AudioDSP
DSP Algorithm code for Audio Plugin <br>
**[blog](https://blog.naver.com/rbdus0715/224140506531)**: documented what I learn on my blog<br>

## requirements
- CMAKE
- SDL2

## build & run
```bash
mkdir -p build && cd build
cmake ..
make
```

```bash
#/build
./AudioDSP
```
- place test.wav in assets/audio/ directory
